# Dataset

This recipe uses the official MUMU Challenge training data for EUMU tagging
head training. No external labeled dataset is added to train detection or
captioning models.

## Training Data Structure

Place the official training files under:

```text
data/
  train_data/
    train_tag_quality.jsonl
    train_tag_scene.jsonl
    train_tag_event.jsonl
    train_caption.jsonl
```

Each tagging row must provide an image path through `image`, `image_path`,
`path`, or `image_fname`. If rows only contain `image_fname`, pass one or more
image roots with `IMAGE_ROOTS=/path/a:/path/b`.

## Derived Tagging Rows

The recipe builds additional supervision only from official training
images/captions:

```bash
SOURCE_DIR=data/train_data \
CAPTION_JSONL=data/train_data/train_caption.jsonl \
IMAGE_ROOTS=/path/to/train/images \
bash training/run_prepare_tagging_data.sh
```

Outputs:

```text
training_runs/data/tagging_train.jsonl
training_runs/data/quality_synthetic_train.jsonl
training_runs/data/quality_synthetic_calib.jsonl
training_runs/data/event_caption_pseudo.jsonl
```

Quality pseudo rows are generated by applying synthetic blur, noise, low-light,
underexposure, overexposure, high-contrast, low-contrast, motion-blur, and JPEG
compression artifacts to official training images. Event pseudo rows are mined
from official training captions with high-precision keyword rules.

## Validation Data Structure

For threshold search, place local validation data under:

```text
data/
  val_data/
    quality/
      gt.json
      images/
    scene/
      gt.json
      images/
    event/
      gt.json
      images/
```

The local model-selection protocol used separate validation resources by
output type: KonIQ10K for quality, Places365 for scene, USED-test for event,
LVIS v1 for detection, and COCO Karpathy validation plus Flickr30K validation
for captioning.

Challenge test images are used only for final prediction generation. Test
annotations are not used for training, threshold search, or tuning.
